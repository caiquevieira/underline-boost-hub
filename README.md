# UnderlineLAB

Crie uma Landing Page B2B de alta conversão para a empresa de tecnologia "UnderlineTec", em português (pt-BR). Use o logo anexado (letra "u" preta com underline sobre fundo amarelo) como identidade visual — pode recriá-lo em SVG vetorial para nitidez.

1. PALETA & IDENTIDADE:
- Fundo principal: dark mode elegante (#0D0D11 ou #0F0F12)
- Accent: amarelo marcante #FFC700
- Textos: branco #FFFFFF e cinza secundário #A1A1AA
- Estilo: B2B SaaS moderno, focado em conversão e automação comercial
- Tipografia: Inter ou Plus Jakarta Sans
